# حصن المسلم (Hisn Al Muslim)

## نظرة عامة
**حصن المسلم** هو تطبيق إسلامي بمستوى إنتاجي تم بناؤه باستخدام Flutter (الإصدار 3.1.0). يعمل كأداة روحية شاملة، حيث يدمج القرآن الكريم، الأذكار، مواقيت الصلاة، جدولة الأذان، القبلة، والمزيد. تم تصميم المشروع مع تركيز قوي على **تجربة الاستخدام بدون إنترنت**، **تصميم Material 3**، و**الأداء العالي**.

## أبرز المعالم الهندسية
- **جدولة الأذان الأصلية:** تم تطوير `AdhanScheduler` مخصص باستخدام Android Native Kotlin و `AlarmManager` و `WorkManager` للتغلب على قيود إضافات الإشعارات عبر المنصات.
- **منطق النافذة المنزلقة (Sliding Window):** تنفيذ منطق "النافذة المنزلقة" المتطور لجدولة الأذان (نافذة لمدة 7 أيام) لضمان موثوقية بنسبة 100% مع تحسين استهلاك البطارية.
- **واجهة مستخدم زمنية ديناميكية:** تتطور الواجهة على مدار اليوم بناءً على وقت الصلاة الحالي، باستخدام سمة Material 3 مخصصة تسمى **Noor M3**.
- **الأولوية للعمل بدون إنترنت:** يدعم التنزيل التلقائي لملفات القرآن JSON والأصول عند أول تشغيل لضمان العمل الكامل بدون اتصال بالإنترنت.

## المعمارية والتقنية
- **إطار العمل:** Flutter مع `flutter_bloc` لإدارة الحالة.
- **الطبقة الأصلية (Native):** Kotlin لتكامل أندرويد العميق.
- **التخزين:** SQLite (`sqflite`) لبيانات القرآن و `SharedPreferences` لإعدادات المستخدم.
- **الشبكات:** `Dio` لجلب مواقيت الصلاة عبر AlAdhan API والتلاوات عبر Quran Cloud.

## التحديات والحلول
- **التحدي:** تكرار الإشعارات ومشاكل الموثوقية في إصدارات أندرويد الحديثة.
- **الحل:** تقوية منطق الجدولة في الطبقة الأصلية وتنفيذ تصريحات Foreground Service الصحيحة وسياسات Exact Alarm.
- **التحدي:** إدارة حجم التطبيق مع الأصول عالية الجودة.
- **الحل:** تحسين حجم التطبيق (70-90 ميجابايت) عبر الـ Minification، وتقليص حجم الأصول، وتحسين موارد الـ Splash والأيقونات.
